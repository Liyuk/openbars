# Provider keys and limits

These are public free-tier notes recorded in this repository; limits, coverage and history can change. Check the official pages before signing up. Provider terms differ: store data locally for personal use, do not redistribute it, and follow each provider's terms. Enter credentials through interactive `openbars init` or edit the private, uncommitted `.env` yourself.

| Provider | Official page | Key, free limits and history |
| --- | --- | --- |
| Alpaca | [Market Data API](https://docs.alpaca.markets/docs/about-market-data-api) | Account and key required. Repository notes 200 requests/minute and SIP history from 2016; feed and recent-data restrictions apply. |
| Massive | [Pricing](https://massive.com/pricing) | Key required. Repository notes 5 requests/minute in the free tier, with a default pacing of 4. Basic history is approximately a two-year (730-day) rolling window; check the pricing page for current details. |
| yfinance | [Documentation](https://ranaroussi.github.io/yfinance/) | No registration or token. No published fixed quota; history varies by instrument and upstream; the project's 30 requests/minute is a conservative setting, not an official limit. |
| BaoStock | [Documentation](http://www.baostock.com/) | No registration or token. No official fixed quota; history varies by instrument, see the documentation. Install `openbars[baostock]`. |
| Binance | [Public market data](https://developers.binance.com/docs/binance-spot-api-docs/rest-api/market-data-endpoints) | Public market data needs no registration or token. Request weights are limited per IP; history depends on the pair's listing date; see the official docs. |
| Coinbase | [Exchange candles](https://docs.cdp.coinbase.com/exchange/reference/exchangerestapi_getproductcandles) | Public market data needs no registration or token. Up to 300 candles per request, history varies by product; public API rate limits also apply. |
| AKShare | [Documentation](https://akshare.akfamily.xyz/) | No registration or token. No uniform official fixed quota; history varies by upstream and instrument. Install `openbars[akshare]`. The Hong Kong entry `akshare` is used only as corroboration and does not enter plan/run; the A-share entry `akshare_ashare` is wired into the CLI, with `feed: eastmoney` (default) or `sina`, and is positioned as a low-frequency backup. The library is MIT but does **not** relicense upstream quotes; follow Eastmoney/Sina terms, store locally, never redistribute. |
| Tushare | [Official documentation](https://tushare.pro/document/2?doc_id=27) / [Terms](https://tushare.pro/document/1?doc_id=405) | Token required. The free personal tier is about 120 points: roughly 50 requests/minute and 8,000/day, **unadjusted daily bars only** (qfq/hfq and `adj_factor` normally need a higher tier and are not used). Read the token only from `TUSHARE_TOKEN`; never commit it. Entry point `providers.tushare`; install `openbars[tushare]`. The licence is personal, non-transferable, non-commercial and revocable; public use must carry Tushare's required attribution as stated in its terms. Store locally, never redistribute. |
| Futu OpenD | [OpenAPI](https://openapi.futunn.com/) | Run and log in to a local OpenD yourself; OpenBars only reads `providers.futu.host` / `port` and does not handle login. A login does not imply Hong Kong quote rights; the level, history-K quota and mainland/international status depend on the account and official terms. Install `futu-api` yourself. The adapter exists but is not wired into the CLI. |
| LongPort | [OpenAPI](https://open.longportapp.com/) | A LongPort account and developer verification are required. Reference `providers.longport.app_key` / `app_secret` / `access_token` as `${ENV}` values such as `${LONGPORT_APP_KEY}`; never write plain text. Free core-API / Hong Kong LV1 versus paid LV2 follow LongPort's current terms. Install the `longport` SDK yourself. The adapter exists but is not wired into the CLI. |
| Twelve Data | [Pricing](https://twelvedata.com/pricing) | Key required. Implemented for US 1h, regular session only, not daily bars. Repository notes 8 API credits/minute, 800 API credits/UTC day and up to 5,000 bars/request; history depends on plan and instrument. |

US 1h providers include Alpaca, Massive, yfinance and Twelve Data; hourly runs need a version that includes the hourly support.

Alpha Vantage ([official API key page](https://www.alphavantage.co/support/#api-key)) and Tiingo ([official documentation](https://www.tiingo.com/documentation/general/overview)) are **not implemented** and cannot be used through the current CLI. The disabled Alpha Vantage entry in the example config is not a usable data source. Tushare is implemented as the optional `providers.tushare` adapter (free-tier unadjusted daily bars; needs `TUSHARE_TOKEN` and `openbars[tushare]`).
